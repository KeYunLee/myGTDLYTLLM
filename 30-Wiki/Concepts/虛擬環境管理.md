# 虛擬環境管理

## 核心定義
虛擬環境（Virtual Environment）是 Python 開發中隔離專案相依套件的機制，確保不同專案的套件版本互不干擾。在 ML 工程場景中，通常搭配 CUDA 版本管理一起考量。

## 運作原理

### 三種主流工具比較

| 面向 | venv / virtualenv | virtualenvwrapper | conda |
|------|-------------------|-------------------|-------|
| 建立 | `virtualenv venv_name` | `mkvirtualenv venv_name` | `conda create -n name python=3.x` |
| 啟動 | `source venv_name/bin/activate` | `workon venv_name` | `conda activate name` |
| 停用 | `deactivate` | `deactivate` | `conda deactivate` |
| 刪除 | `rm -rf venv_name` | `rmvirtualenv venv_name` | `conda env remove -n name` |
| 列出 | `ls` | `lsvirtualenv` | `conda env list` |
| 適用 | 純 Python | 多專案管理 | 含 C/CUDA 相依 ★ML 推薦 |

### conda 環境管理（ML 場景推薦）
```bash
# 建立含 CUDA 的環境
conda create -n ml_env python=3.10
conda activate ml_env
conda install pytorch torchvision cudatoolkit=11.8 -c pytorch -c nvidia

# 匯出與重建
conda env export > environment.yml
conda env create -f environment.yml
```

### 選擇指南
- **純 Python 專案**：`venv` 足夠，內建無需安裝
- **多 Python 專案管理**：`virtualenvwrapper`（統一存放於 `~/.virtualenvs`）
- **ML / CUDA 專案**：`conda`（可管理非 Python 的 C/CUDA 函式庫）

## 優點與限制
- **優點**：套件版本隔離；可重現環境（`environment.yml` / `requirements.txt`）
- **限制**：conda 環境體積大；多環境並存時磁碟佔用可觀；Jetson 上 conda 不支援 ARM 官方頻道
