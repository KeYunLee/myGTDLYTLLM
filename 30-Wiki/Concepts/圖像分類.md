# 圖像分類（Image Classification）

## 核心定義
圖像分類是電腦視覺的基礎任務：給定一張影像，輸出其所屬類別標籤。與物件偵測不同，圖像分類**只判斷「What」（是什麼），不判斷「Where」（在哪裡）**。

## 運作原理

### 主流架構演進

| 年代 | 架構 | 關鍵貢獻 |
|------|------|---------|
| 2012 | AlexNet | 深度 CNN 突破；ReLU / Dropout |
| 2014 | VGGNet | 深層小卷積（3×3）堆疊 |
| 2015 | ResNet | 殘差連接（Residual）；解決梯度消失 |
| 2017 | MobileNet | 深度可分離卷積；邊緣設備友善 |
| 2020 | EfficientNet | 複合縮放（深度/寬度/解析度） |
| 2021 | ViT | Vision Transformer；Patch 切割 + Self-Attention |

### 典型訓練流程（PyTorch）
```python
import torchvision.models as models
import torchvision.transforms as transforms

# 1. 資料預處理
transform = transforms.Compose([
    transforms.Resize(256),
    transforms.CenterCrop(224),
    transforms.ToTensor(),
    transforms.Normalize(mean=[0.485, 0.456, 0.406],
                         std=[0.229, 0.224, 0.225])
])

# 2. 遷移學習（Transfer Learning）
model = models.resnet50(pretrained=True)
model.fc = nn.Linear(2048, num_classes)   # 替換最後一層

# 3. 訓練（Fine-tuning）
optimizer = torch.optim.Adam(model.parameters(), lr=1e-4)
criterion = nn.CrossEntropyLoss()
```

### 評估指標
- **Top-1 Accuracy**：預測類別 = 真實類別的比例
- **Top-5 Accuracy**：真實類別在前 5 預測中的比例
- **Confusion Matrix**：各類別的混淆矩陣，識別易混淆類別

### 遷移學習策略
| 策略 | 做法 | 適用場景 |
|------|------|---------|
| Feature Extraction | 凍結全部層，只訓練新 FC | 訓練資料極少 |
| Fine-tuning | 解凍後段層，整體微調 | 訓練資料中等 |
| Full Training | 全部重新訓練 | 訓練資料充足且領域差異大 |

## 優點與限制
- **優點**：任務定義清晰；預訓練模型豐富（ImageNet 預訓練）
- **限制**：只輸出類別，不包含位置資訊；對遮擋、角度變化敏感
