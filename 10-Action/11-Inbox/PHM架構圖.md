## Real-time Prediction Pipeline

```
sequenceDiagram
    participant Sensor
    participant OnlineAPI
    participant FeatureService
    participant ModelService
    participant AnomalyDetection
    participant AlertSystem
    participant Database
    
    Sensor->>OnlineAPI: real-time data
    OnlineAPI->>FeatureService: extract_features()
    FeatureService->>ModelService: predict(features)
    ModelService->>AnomalyDetection: prediction_result
    AnomalyDetection->>AlertSystem: anomaly_detected
    AlertSystem->>Database: log_prediction
    AlertSystem->>OnlineAPI: prediction + alert
    OnlineAPI->>Sensor: response
```
