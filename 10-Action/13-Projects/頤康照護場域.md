# 頤康照護場域專案

> 與崇恩集團合作，使用電腦視覺辨識照護行為（換尿布、翻身拍背、餵食等），部署於長照機構場域。
> 聯絡人：Greg 0910782928

---

## 系統架構

```
影片（mp4）
  ├─ YOLOv5（人體/尿布偵測）→ txt 結果
  └─ Openpose（骨架估測）→ pose_json
        └─ Multi Object Tracker（opjson2trackerDF）→ Tracker.csv（含 label）
              └─ DDNet 訓練 / 推論 → 動作分類結果 → 視覺化影片
```

## 執行 SOP

### 0. 影片切割

```bash
ffmpeg -i xxxx.mp4 -ss xx:xx:xx -to xx:xx:xx output.mp4
```

### 1. Openpose 骨架輸出

```bash
./build/examples/openpose/openpose.bin \
  --video <INPUT_MP4> --display 0 \
  --write_video <OUTPUT_MP4> --write_json <JSON_DIR>
```

### 2. Multi Object Tracker

```bash
bash script/tracker_caregiver_caring.sh
# 核心參數：--maxDistance 100 --filter 10 --zeromax 9
```

### 3. Labeling SOP

1. 開啟 Tracker.csv 與 Tracker.mp4
2. 新增欄位 `label`
3. 依序篩選 person_id → 查看對應影片段落 → 標記動作起迄區間
4. 重複直至所有 person_id 完成

### 4. 資料前處理

```bash
bash script/prepare_caregiver_caring.sh
# trainset / validset / testset → pkl
```

### 5. DDNet 訓練

```bash
bash script/train_caregiver_caring.sh
# 輸出：output/caregiver_caring_<DATETIME>/my_model.h5
```

### 6. 推論

```bash
bash script/inference_caregiver_caring.sh
# 輸出：inference_<DATETIME>/test_result.csv
```

### 7. 視覺化

```bash
bash script/visualize_caregiver_caring.sh
# 需提供：VIDEO_PATH, POSE_PATH, ACTION_PATH（可選）
```
